# FiveM Lua Snippets & Helper Functions

Eine Sammlung von nützlichen, performance-optimierten Helper-Funktionen für FiveM (Lua), die modular in eigenen Ressourcen wiederverwendet werden können.

## 📦 Inhalt
* **Discord Webhook Formatting:** Saubere Logs mit Embed-Unterstützung und Color-Codes.
* **Vector & Distance Helpers:** Optimierte Distanzprüfungen zur Schonung des Resmon-Werts (`#(vector1 - vector2)` statt `GetDistanceBetweenCoords`).
* **Formatierung:** Währungs- und Datumsformatierung für NUI/UI-Ausgaben.

## 🚀 Nutzung
Die entsprechenden Funktionen einfach in die `shared/`- oder `client/server/`-Skripte deiner Ressource kopieren oder als Dependency einbinden.

## ⚡ Performance
Alle Snippets sind auf minimale CPU-Execution-Time (0.00ms idle) ausgelegt.
